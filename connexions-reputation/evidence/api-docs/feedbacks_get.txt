/feedbacks/get
The following API call allows you to get the feedback left by a customer as raw data.
This is ideal if you would like complete control over styling the feedback and wish to apply your own Schema Markup.
Alternative #1) You can use our
/widget/get-html
API, which includes styling and markup.
Alternative #2) You can use our
JSON Endpoint
for raw reviews and response data feed.
